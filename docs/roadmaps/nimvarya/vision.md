# Vision — agent-agnostic-browser-bridge

**Objective:** Extract boky's working extension↔WebSocket-relay↔MCP path into a standalone, boky-free Chrome-control tool in this repo that any MCP-capable terminal AI coding tool can point at to navigate, read, find, click, type, screenshot, and query page console logs and network requests of a real Chrome tab, with no Claude-account dependency.

**Success definition:** Done means all of the following hold locally: (1) a separate unpacked MV3 extension (own manifest, own name, no boky domain/provider/session code) loads in any Chrome profile with no sign-in and connects out to the relay; (2) a standalone relay process starts from a repo script (not requiring boky's nest-host WorkflowEngineModule) and routes command / command-response / observation frames between one extension and N controllers; (3) a stdio MCP server exposes a generic tool set — at minimum navigate, getPageText, readPage, findElement, clickElement, typeText, captureTab, plus readConsoleMessages and readNetworkRequests (queryable ring buffer, with a clear-since/limit parameter) — and none of boky's provider/session/storage probes; (4) a single MCP config snippet (command + args) documented in the tool's README works unchanged for Claude Code, Codex CLI, Gemini CLI and Cursor agent, verified by hand with at least two of them; (5) a mechanical parity check asserts MCP-advertised actions == extension command handler cases, mirroring today's check-command-parity; (6) tsc --noEmit, eslint --max-warnings 0, and vitest pass for the new code with unit tests for the frame protocol/ring buffers and integration tests for relay routing and the MCP tool dispatch; (7) boky's existing extension, bridge, and verify pipeline keep passing unchanged.

**Domain shape:** technical — The task is developer tooling machinery — extracting and generalizing a Chrome extension, a WebSocket relay, and an MCP stdio server — with no business entities or rules a domain expert would recognize.

Written at horizon 1 (2026-09-02). Stable; later horizons read, never rewrite.
